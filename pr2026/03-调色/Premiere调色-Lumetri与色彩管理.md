## 一、打开 Lumetri 面板

菜单：**窗口 → Lumetri 颜色**。

选中时间线上的片段后，在 Lumetri 面板里从上到下按分组调。调色是有顺序的：先把每个镜头**校正**到正常，再谈风格。

---

## 二、一级校正：基本校正分组

「基本校正」分组做两件事：白平衡 + 影调。

| 控件 | 作用 | 要点 |
|---|---|---|
| 输入 LUT | Log / 伽马素材先套还原 LUT | 摄影机拍的 Log 素材第一步必须先还原（见第十节） |
| 白平衡：色温 / 色彩 | 校掉偏色 | 用白平衡吸管点画面里本该是灰色的地方 |
| 色调 | 白平衡里的洋红-绿轴 | 偏绿偏品就往回拉 |
| 曝光 | 整体亮暗 | 先看直方图调到不过曝不死黑 |
| 对比度 | 反差 | 曝光之后再动 |
| 高光 / 阴影 | 救回亮部 / 暗部细节 | 大光比素材先收高光 |
| 白色 / 黑色 | 定白场 / 黑场 | 决定画面"通不通透" |
| 饱和度 | 全局鲜艳度 | 一级先别拉满，留给创意分组 |

---

## 三、创意分组

| 控件 | 作用 |
|---|---|
| Look | 一键电影感预设（LUT 风格），可叠在自己的校正之上 |
| 淡化胶片 | 抬黑场、做胶片灰雾感 |
| 锐化 | 细节清晰度 |
| 饱和度 | 风格层饱和度（区别于基本校正的全局饱和度） |
| 色彩平衡 | 亮部/暗部分别偏色，做色调倾向 |

---

## 四、曲线分组

| 曲线 | 用途 |
|---|---|
| RGB 曲线 | 点控明暗反差：S 形曲线提反差，暗部下拉、亮部上推 |
| 色相 vs 色相 | 把画面里"天空的蓝"换成另一种蓝 |
| 色相 vs 饱和度 | 单独压/提某颜色的鲜艳度（比如让红更跳） |
| 色相 vs 亮度 | 单独压暗某颜色（比如压暗背景的绿） |

---

## 五、色轮分组

三个色轮 + 提亮压暗：

- **阴影（Lift）**：暗部往哪偏色；
- **中间调（Gamma）**：主体肤色所在区间；
- **高光（Gain）**：亮部往哪偏色。

思路：暖调片子高光偏橙、阴影偏青；冷调反之。这是达芬奇 Lift/Gamma/Gain 思想在 PR 里的对应物（详见[《达芬奇调色-节点工作流入门与进阶》](./达芬奇调色-节点工作流入门与进阶.md)）。

## 六、HSL 辅助（二级调色）

基本校正管"整个画面"，HSL 辅助管"画面里的某一种颜色"。

入口：Lumetri 面板 → **HSL 辅助**分组：

1. **键**：用取色器在画面上点选要改的颜色（加按 Shift 可多点取色）；
2. 调选择范围：**H（色相）、S（饱和度）、L（明度）**三个滑块 + **模糊**，让选区干净不溢边；
3. **更正**：选区套好后，下面的色轮 / 饱和度只改选中的颜色。

典型用途：把天空调蓝、把墙皮颜色单独换掉、压暗背景突出主体。

---

## 七、晕影

Lumetri 面板 → **晕影**分组：

| 控件 | 作用 |
|---|---|
| 数量 | 四周压暗的程度 |
| 中点 | 晕影从多远处开始 |
| 圆度 | 椭圆/圆形变形 |
| 羽化 | 晕影边缘多柔 |

用途：把观众视线往画面中心收；人物采访、产品特写常用。

## 八、自动调色与镜头匹配（免费 AI）

| 功能 | 入口 | 费用 |
|---|---|---|
| 自动（Auto Color） | Lumetri 面板 → 基本校正 →「自动」按钮，自动校正曝光/对比度/白平衡，结果可用强度/颜色/光感滑块微调 | **免费**（Assistive AI，大陆可用） |
| 比较视图匹配 | 节目监视器 →「比较视图」→ 选参考帧 →「匹配」，一键把当前镜头匹配到参考镜头的色调光线 | **免费** |

流程：粗剪完 → 挑一个"标准镜头"先手工调好 → 其余同场景镜头挨个「比较视图 → 匹配」→ 再手工微调差异。同场景多个镜头一秒统一，是 2026 版最省时间的调色动作。

## 九、色彩管理

| 操作 | 菜单路径 |
|---|---|
| 项目色彩空间 | 文件 → 项目设置 → 色彩管理 → 色彩空间（Rec.709 / sRGB） |
| 监看色彩空间 | 节目监视器 → 扳手（设置）→ 色彩管理 → 显示色彩空间 |

要点：交付网络视频默认 Rec.709 / sRGB 即可；素材是广色域 / Log 时靠输入 LUT 还原，别在中间环节反复转空间。

---

## 十、LUT 的使用

| 操作 | 路径 |
|---|---|
| 套用输入 LUT | Lumetri 面板 → 基本校正 → 输入 LUT → 下拉选择 |
| 挂自定义 LUT | 输入 LUT → 浏览 → 选本地 `.cube` 文件 |

顺序：Log 素材先套摄影机官方还原 LUT（如 S-Log3 的 Rec.709 还原），再在上面做二级；风格 LUT（电影感 Look）放「创意」分组叠加。

## 十一、调色顺序心法

```mermaid
flowchart LR
    A[看直方图/示波器] --> B[白平衡<br/>色温/色彩]
    B --> C[影调<br/>曝光→对比度→高光阴影]
    C --> D[一级色轮<br/>定整体色调倾向]
    D --> E[二级<br/>HSL辅助 改局部颜色]
    E --> F[创意 Look<br/>+ 淡化胶片]
    F --> G[晕影收视线]
    G --> H[同场景镜头<br/>比较视图匹配统一]
```

一句话：**先校正（把每个镜头调正常），后风格（Look/晕影），最后统一（镜头间匹配）**。
