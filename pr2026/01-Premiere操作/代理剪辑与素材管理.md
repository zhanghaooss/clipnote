# 代理剪辑与素材管理

> 适用版本：**Adobe Premiere v26.5.2**。本文整理代理工作流、收录设置、素材管理与 DIT 现场素材流程。

## 2026 变化概览

- **Frame.io V4 原生面板（25.6 起）**：「窗口 → Frame.io」直接在 PR 里收客户批注；Creative Cloud 订阅自带免费档（2 个用户、最多 5 个活跃项目、250GB 存储，2026-10 官方页口径）。
- **Media Intelligence（25.2 起）**：素材智能搜索、查相似帧（节目监视器右键 →「查找相似帧…」），免费。
- **「匹配源」预设扩展到音频声道/采样率（26.5）**，导出更省心。
- 收录/代理流程不变：新建项目勾收录 → 自动生成代理；右键素材 →「代理 → 创建代理」手动跑。

## 一、为什么要代理

拍 4K/高码率素材时，电脑实时回放会卡——代理工作流 = 剪辑时用**低码率小文件**（H.264 代理），导出时自动回链**原片**输出，画质不损、剪辑顺滑。

---

## 二、自动收录 + 代理

1. 新建项目对话框 → 勾「**收录设置**」；
2. 收录动作选「创建代理」；
3. 格式选 **H.264**，预设选代理分辨率（如 1280×720 或 1024×546）；
4. 之后导入素材 = PR 一边拷贝一边生成代理。

---

## 三、手动创建代理

素材已经导进来了才想起做代理？

1. 项目面板选中素材 → 右键 →「**代理 → 创建代理**」；
2. 选格式/预设 → 确定；
3. PR 自动调起 **Media Encoder** 后台队列渲染（Media Encoder 是随 PR 一起安装的辅助程序，不单独收费）；
4. 渲染完弹窗提示，代理自动挂接。

---

## 四、代理 / 原素材切换

- 节目监视器（或源监视器）底部**扳手菜单** → 勾/取消「**切换代理**」；
- 剪辑时切到代理（流畅），导出前切回原素材（高质量）。

---

## 五、素材管理规范

1. **素材箱分类**（`Ctrl+/` 新建）：按场景/机位/内容分，别全堆根目录。
2. **命名规范**：场景-镜头-条数（如 `S01_Take03`），别用"新建剪辑 01"。
3. **颜色标签**：素材箱/素材右键 → 标签颜色，给"已选用/待审/废弃"上色。
4. **废弃素材不删**：拉进 `_废弃` 素材箱，避免手滑误删。
5. **本地缓存定期清**：「编辑 → 首选项 → 媒体缓存」→ 删除未使用缓存。

---

## 六、脱机素材与重新链接

打开工程提示"媒体脱机"？

1. 项目面板里脱机素材显示离线色；
2. 右键 →「**链接媒体**」→ 指到素材新位置；
3. 勾「相对链接」，同目录结构的素材会一次性全部找回。

---

## 七、项目打包（DIT 交付思路）

给下一环（调色/剪辑搭档）交活时：

1. 菜单「文件 → 项目管理」→「收集文件并复制到新位置」→ 选目标路径；
2. 确认：素材 + 缓存 + 工程文件全部收齐；
3. 「排除未使用剪辑」按需勾选（交工程给别人时不勾，自己归档时可勾）；
4. 拷贝前把代理文件夹一起带上，对方打开工程不用重新生成代理。
