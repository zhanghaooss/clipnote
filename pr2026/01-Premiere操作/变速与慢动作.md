# 变速与慢动作

> 适用版本：**Adobe Premiere v26.5.2**。本文涵盖时间重映射、速度/持续时间、帧采样/帧混合/光流法、生成式延长、Twixtor 与嵌套。

## 2026 变化概览

- **生成式延长（Generative Extend）**：直接拖时间线上剪辑的开头/结尾边缘即可 AI 补帧，无缝延伸镜头（v25.2 首发，26.5 增强支持 360p–4K、任意宽高比）。
- **费用提醒**：生成式延长按 Firefly 积分计费（1080p30 ≈ 125 积分/秒），且**中国大陆账号不可用**（Firefly 服务官方明示在华不可用）；国内用户用本文第二~四节的传统方法即可。
- 比率拉伸工具（`R`）、时间重映射、光流法均为长期稳定的内置功能，不另收费。

## 一、速度/持续时间（整体变速）

- 选中素材 → 右键 →「速度/持续时间」，或快捷键 `Ctrl+R`；
- 速度填 **50%** = 慢动作；填 200% = 快动作；
- 勾「**倒放速度**」= 倒放；
- 勾「**保持音频音调**」= 加速后声音不变调；
- 时长与速度联动，改一个另一个自动跟着变。

> 工具法：工具栏「比率拉伸工具」（`R`），直接拖素材边缘改时长，PR 自动反算速度。

## 二、时间重映射（一段素材内忽快忽慢）

适合：前半段正常 → 中间突然慢动作 → 后面恢复正常。

1. 选中素材 → 右键 →「**显示剪辑关键帧 → 时间重映射 → 速度**」；
2. 素材上出现一条速度线；按住 `Ctrl` 在速度线上**点一下 = 加一个关键帧**（把素材切成几段变速区）；
3. **往上拖速度线 = 加速，往下拖 = 减速**；
4. 关键帧之间的小手柄可以拉速度过渡曲线（缓入缓出）；
5. 精度微调：效果控件面板 →「时间重映射 → 速度」里用数字打关键帧。

```mermaid
flowchart LR
    A[素材正常速度 100%] --> B[Ctrl加点打关键帧]
    B --> C[下拉速度线到 30%<br/>进入慢动作段]
    C --> D[再打关键帧抬回 100%]
    D --> E[拉关键帧间手柄<br/>做缓入缓出]
```

### 坡度变速的实战节奏（配合音乐）

- 典型曲线：**500% → 100% → 25%**（由快到正常，再落到升格慢动作）；加速 / 减速的具体数值按**音乐节奏**确定。
- 打点手法：在速度线上按下关键帧后**留出约三帧距离**再拖速度；向右拖小针的距离要有数（几帧，3~5 帧），并注意构图；也可把一个镜头逐帧"刀"在另一个镜头上（如 100 帧 → 25 帧）。
- **冲击感**：坡度变速"**先减速、后加速**"，画面反而更稳；过渡处**中间放几帧**做缓冲。
- **顺序：先变速、后截剪**——先定好速度曲线，再回头剪切点（与第六节"先插帧后精剪"同理）。
- 音乐上**鼓点密集的地方**可以切画面元素，或叠特效转场，只要一个动感画面即可；留白制造起伏感，配合音乐特点。

## 三、帧采样 / 帧混合 / 光流法

慢动作发"卡"？右键素材 →「**时间插值**」（旧称帧采样），三档选：

| 模式 | 原理 | 效果 |
|---|---|---|
| 帧采样（Frame Sampling） | 抽重复帧 | 默认，快动作能用，慢动作会顿 |
| 帧混合（Frame Blending） | 相邻帧混合 | 稍顺滑，有轻微拖影 |
| **光流法（Optical Flow）** | AI 算中间插帧 | **慢动作最平滑**，但导出渲染慢 |

> 素材本身 60/120fps 拍的，直接降速到 25% 就够丝滑；30fps 硬降速才需要光流法。

## 四、生成式延长（AI 补帧）

1. 时间线上把鼠标放到视频剪辑的**开头或结尾边缘**，等出现生成扩展提示后**直接往外拖**；
2. PR 云端生成补帧片段，自动接到原片上；
3. 生成结果（H.264 MP4 / wav）存到「项目设置 → 暂存盘」位置。

| 规格 | 消耗 |
|---|---|
| 1080p30 | 125 积分/秒 |
| 1080p24 / 720p30 / 4K24 | 100 / 75 / 150 积分/秒 |
| 4K30 | 175 积分/秒 |

**限制与费用标签：**
- 🔴 **中国大陆不可用**（Firefly 服务在华不可用，官方明示）；
- 🟡 生成片段不能含对话（会被静音）、不能含音乐，只支持单声道/立体声，只能从一端延长；
- 🟡 积分只对 Firefly 计划 / Creative Cloud Pro 等高档订阅开放，单应用 PR 订阅会遇到付费墙。

## 五、插件方案

- **Twixtor（RE:Vision Effects）**：专业级光流插帧插件，效果比 PR 内置光流法更稳，适合高要求慢动作；付费插件、提供试用（未授权输出带水印）。装完在「视频效果 → RE:Vision Plug-ins → Twixtor」拖到片段上。
- **RSMB（ReelSmart Motion Blur）**：变速后画面太"硬"时加运动模糊；同厂插件，付费、可试用。
- 内置替代：时间重映射变速后，在效果控件里开「时间重映射」的运动模糊选项。
- **Filmimpact（转场插件）**：一组非 AI 的转场过渡插件（v26.2 已引入 Film Impact 现代效果/过渡集），鼓点密集处想接一个动感画面时好用。

## 六、实操建议

1. **前期高帧率是升格质量的前提**：拍摄就上 **50/60p 或更高**（120/240p），PR 里只做 25%~50% 降速；素材拍够高帧率，连光流法都可以省，更省插件和渲染。
2. **先插帧后精剪**：定好变速点再回头剪切点，避免反复重渲染。
3. **嵌套提速**：多段变速素材先右键「嵌套」再整体调，轨道更干净。
4. **声画同步检查**：变速片段如果带人声，勾「保持音频音调」，并回时间线对一遍口型。

> **2026 现状一句话**：免费内置的**时间重映射 + 光流法**已能覆盖大多数升格需求；Firefly 生成式延长虽已支持 360p–4K、任意宽高比，但按积分计费且 🔴 中国大陆不可用（见第四节标签）。国内可用流程 = **前期高帧率素材 + 时间重映射坡度变速 + 光流法/帧混合**。
