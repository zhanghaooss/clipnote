# 字幕与文字工作流

> 适用版本：**Adobe Premiere v26.5.2**。本文已按 2026 版现状更新（基本图形面板、旧版标题均已移除）。

## 2026 变化概览

- **v25.0（2024-10）起「基本图形（Essential Graphics）」面板已移除**，标题/字幕编辑统一进**属性面板**；浏览 MOGRT 模板改用**图形模板面板**。
- **v23.0（2022-10）起「旧版标题（Legacy Titler）」已移除**，无法再新建。
- **v25.2 起新增「翻译字幕」**（多语言/双语字幕）。
- **v26.3（2026-06）新增「逐字（单词）字幕」**：一次蹦一个词的快节奏社交字幕。
- 语音转文本（Speech to Text）**免费、含在订阅内、个人无公平使用限额**，支持简体中文（普通话），语言包下载后可离线转录。

## 一、手动开放式字幕（旧版流程，已不推荐）

1. 项目面板右下角「新建项」→ **「字幕 → 开放式字幕（Open Captions）」**；
2. 把字幕拖到时间轴字幕轨上，拉长/缩短控制显示时长；
3. 项目面板里右键该字幕 →「速度/持续时间」可改精确时长；
4. 在**属性面板**（窗口 → 属性）里改字体、颜色、位置、大小；
5. 一条字幕对应一句话，下一句**新建一条**字幕（别在一条里堆全文）。

> 字幕标准可选 CEA-608 / CEA-708 / Teletext / 开放式字幕；源监视器底部扳手 →「字幕显示 → 设置」切标准与通道。

## 二、自动转录 → 自动字幕（推荐流程）

1. 菜单 **「窗口 → 文本」** 打开文本面板（三个选项卡：转录文本 / 字幕 / 图形）；
2. **「转录文本」选项卡 →「转录序列」**（CC 图标按钮）→ 选语言「简体中文」→ 自动生成带时间轴的转录稿，并自动按发言者 1 / 发言者 2 标注；
3. 在转录稿里**选中错字直接改**，或选中句子按 Delete = 波纹删除对应时间线片段；
4. 点面板上的**漏斗筛选器**：可按「填充词 / 屏蔽词语 / 暂停 / 扬声器」筛出，逐条或一键删除（屏蔽词可一键静音/bleep）；
5. 切到 **「字幕」选项卡 →「创建字幕」**，PR 自动在时间线生成独立字幕轨。

| 功能 | 费用 | 大陆可用 |
|---|---|---|
| 语音转文本转录/自动字幕 | **免费**（含在订阅，Assistive AI，个人无限额） | 是，语言包可离线 |
| 屏蔽词一键消音 | 免费 | 是 |
| 逐字（单词）字幕，v26.3 | 免费 | 是 |

## 三、逐字字幕 / 翻译字幕

- **逐字字幕**（26.3）：在字幕选项卡里选「单词字幕」样式，一个词一个词蹦出来，适合快节奏短视频；样式自定义后按预览所见导出。
- **翻译字幕**：字幕选项卡 → 顶部「翻译字幕」图标 → 选目标语言 → 自动在时间线**新建一条语言轨**（双语并排）。费用：**免费（Assistive AI）**；注意它走 Google/Microsoft 云翻译通道，国内网络环境下的实际可达性待实测。

## 四、样式批量修改

1. 点击时间线上的**字幕轨**（选中整轨）；
2. 在**属性面板**里改字体/字号/对齐/颜色/边距——整轨所有字幕同步变；
3. 单条微调：点单条字幕单独改。

> 旧笔记里"窗口 → 基本图形 → 编辑/样式"的路径已失效，现在全部在属性面板。

## 五、文字层与 MOGRT 模板

### 1. 普通文字层

- 工具栏选**文字工具 `T`** → 节目监视器里点一下直接打字；
- 选中文字层，在属性面板改字体、大小、颜色、位置；
- 做好一条字幕后，**按住 `Alt` 拖动复制**一条到下一个时间点，改文字即可（效率法）。

### 2. MOGRT 动态图形模板

- 菜单 **「窗口 → 图形模板」** 打开图形模板面板，浏览/我的模板；
- 把 `.mogrt` 拖到时间线 → 属性面板里改可编辑项（文字、颜色、Logo 图）；
- 模板文件本身在「基本图形/动态图形模板」目录，拷贝即用。

### 3. PSD 文字/设计稿

PSD 导入四选项见 [PR基础操作与项目设置](./PR基础操作与项目设置.md) 第四节；分层导入后每层单独改字。

---

## 六、导出 SRT

1. 菜单 **「文件 → 导出 → 媒体」**（`Ctrl+M`）；
2. 在导出设置里展开 **「字幕」** 分组 → 选「创建旁挂字幕文件」→ 格式选 **SRT**（也支持 SCC/MCC/XML/STL/DFXP）；
3. 勾选「导出音频」之外，字幕文件单独生成，可发给抖音/B站后台直接挂。

## 七、常见问题

1. **字幕看不见**：
   - 字体颜色和背景颜色相同 → 改颜色或加描边/阴影；
   - 画面本身是白色且字幕也是白字 → 加黑色描边或半透明底条。
2. **滚动字幕怎么做**：旧版标题已移除，替代做法——文字层做好后右键「嵌套」，再用**比率拉伸工具（`R`）**拖长/缩短，或直接打位置关键帧做上移滚动。
3. **黑场/字幕条**：项目面板「新建项 → 黑场视频」放时间线当底条。
4. **一个字幕文件 = 一句话**：长文案拆条做，别一条塞到底。
5. **字体不显示/缺失**：新字体要先装到系统（Windows 字体目录），重启 PR 后才出现；替换字体提示时选替代字体。
