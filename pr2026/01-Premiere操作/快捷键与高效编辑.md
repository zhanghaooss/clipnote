# 快捷键与高效编辑

> 适用版本：**Adobe Premiere v26.5.2（简体中文）**。快捷键是 PC 键盘（Windows）口径，Mac 用户把 `Ctrl` 换 `Command`、`Alt` 换 `Option`。
> 本文汇总剪辑常用快捷键与高效编辑技巧。

## 2026 变化概览

- v26.0 起，时间线上**直接拖拽剪辑边缘上的过渡手柄**即可加转场，不用再拖效果面板。
- v25.1 起时间线改为圆角设计，视觉上更容易辨认剪辑边界。
- 文本式编辑（Paper Edit / 删转录稿剪片）是 2026 版最大的效率升级，配合快捷键使用，见 [剪辑工作流-粗剪精剪与多轨道](./剪辑工作流-粗剪精剪与多轨道.md)。

## 一、工具栏工具

| 快捷键 | 工具 | 干什么用 |
|---|---|---|
| `V` | 选择工具 | 默认工具，拖素材/调位置 |
| `C` | 剃刀工具 | 在播放头处切断素材（更快的是 `Ctrl+K`） |
| `B` | 波纹编辑 | 拖边缘改长度，后面素材自动跟进不留空 |
| `R` | 比率拉伸工具 | 直接拖素材边缘改时长（连带变速） |
| `Y` | 滑动工具 | 不改时长，只改素材在时间线上的取点 |
| `P` | 钢笔工具 | 画蒙版/关键帧曲线 |
| `H` | 手型工具 | 拖时间线平移 |
| `Z` | 缩放工具 | 框选放大时间线（课上补充） |
| `A` | 向前选择轨道 | 选中目标轨道上播放头之后的所有素材；**双击 A** = 选中该轨道全部素材 |
| `Shift+A` | 向后选择轨道 | 选中播放头之前的素材 |

## 二、时间线编辑

| 快捷键 | 功能 | 备注 |
|---|---|---|
| `Ctrl+K` | 在播放头处切剪刀 | 最常用 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 撤销 / 重做 | |
| `Delete` | 删除选中素材（留空隙） | |
| `Shift+Delete` | 波纹删除（删素材并后移补位） | |
| `Alt+点击` | 快速删除/快速移除某属性 | 课上补充 |
| `Alt+拖动` | 复制素材到新位置 | 按住 Alt 拖 = 副本 |
| `Alt+鼠标拖拽` | 替换素材 | 拖到已有素材上释放 = 替换（保持位置/时长） |
| `Alt+按住拖素材` | 改原素材不影响时间线 | 课上补充 |
| `Shift+E` | 隐藏/启用素材（切换禁用） | 笔记原文「隐藏素材」 |
| `Ctrl+R` | 速度/持续时间 | 详见 [变速与慢动作](./变速与慢动作.md) |
| `Ctrl+D` | 加默认**视频**转场 | |
| `Ctrl+Shift+D` | 加默认**音频**转场 | |
| `Shift+\<` / `Shift+>` | 播放头左右跳 5 帧 | 课上补充 |
| `Shift++` / `Shift+-` | 轨道高度增减 | 课上补充 |
| `S` | 吸附开关 | 素材边缘自动吸到播放头/剪辑点 |
| `~` | 面板整屏最大化 | 鼠标悬在哪个面板就放大哪个；`Ctrl+~` 全屏节目监视器 |
| `=` / `-` | 时间线放大 / 缩小 | |
| `Alt+滚轮` | 时间轴左右平移 | 课上补充 |
| `Alt+左右拖动` | 时间轴缩放 | 课上补充 |
| `Ctrl+S` | 保存 | 勤按 |

**音视频分离**：右键素材 →「取消链接」，再单独拖音频。
**音量关键帧**：按住 `Ctrl` 点音频中间线，点一下加一个音量关键帧。
**嵌套**：选中素材 → 右键 →「嵌套」（Nest），把多段打包成一条序列剪辑。

## 三、播放头与标记

| 快捷键 | 功能 |
|---|---|
| `空格` | 播放/暂停 |
| `M` | 加标记（音乐鼓点、节奏点） |
| `I` / `O` | 标记源/序列入点、出点 |
| `F` | 匹配帧（Match Frame）：在源监视器里打开节目监视器当前帧对应的素材 |
| `,`（逗号） | 源监视器素材**插入**到时间线 |
| `.`（句号） | 源监视器素材**覆盖**到时间线 |
| `Ctrl+/` | 新建素材箱 |

## 四、素材/序列/导出

| 快捷键 | 功能 |
|---|---|
| `Ctrl+I` | 导入素材 |
| `Ctrl+N` | 新建序列 |
| `Ctrl+Alt+N` | 新建项目 |
| `Ctrl+M` | 导出媒体 |
| `Ctrl+T` | （旧版入口，2026 版已移除旧版标题，现用文字工具 `T` 建文字层） |

> 旧笔记里的「新建标题 `Ctrl+T`」对应旧版标题工具；**v23.0（2022-10）起旧版标题已移除，v25.0 起基本图形面板也已移除**，现在文字都用「文字工具 `T` → 属性面板」处理，见 [字幕与文字工作流](./字幕与文字工作流.md)。

## 五、效率技巧（个人实操经验）

1. **左右手分工**：左手管 `空格`/`I`/`O`/`M`/`S`，右手管鼠标；`V`/`C`/`B` 三个工具键按在手边。
2. **吸附 `S` 常开**，只有手动对帧时才关。
3. **关键帧吸附**：效果控件面板里按住 `Shift`，时间线指针会吸附到附近关键帧上（课上补充）。
4. **自动保存**：`编辑 → 首选项 → 自动保存` 设 10 分钟一次。
5. **收藏常用效果**：效果面板里右键常用效果 →「收藏夹」，下次直接在「收藏夹」里找。
6. **文本式编辑替代剃刀**：口播片先转录，在转录稿里删句子剪片，比 `Ctrl+K` 快得多。
7. **波纹思维**：剪访谈时优先用波纹删除（`Shift+Delete`）和波纹编辑（`B`），别用普通 `Delete` 留黑空隙再手动补。

## 六、自定义快捷键

菜单 **「编辑 → 快捷键」**（旧称键盘自定义）：
- 搜命令名（如「波纹删除」）→ 点右侧快捷键列 → 按下你想要的组合键 → 保存预设。
- 建议把「导出帧」「提升」「提取」「添加标记」设成顺手的键。
