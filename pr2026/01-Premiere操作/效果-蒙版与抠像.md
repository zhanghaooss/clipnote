# 效果：蒙版与抠像

> 适用版本：**Adobe Premiere v26.5.2**。本文涵盖效果面板、混合模式、轨道遮罩、关键帧、蒙版与跟踪、抠像与运动模糊。

## 2026 变化概览

- **v26.0（2026-01）AI 对象遮罩**：一键识别并追踪画面里的人/物，自动生成蒙版，不用手 key 帧（**免费，Assistive AI，中国大陆可用**）。
- v26.0 重设计了矩形/椭圆/钢笔蒙版；v26.3 新增「放大（放大镜）」效果。
- v25.5 起 90+ 现代实时效果支持 GPU 加速，实时预览更流畅。

## 一、效果面板结构

窗口 →「效果」面板，五大块：

```
效果面板
├── 收藏夹            ← 常用效果右键收藏
├── 预设
├── 音频效果 / 音频过渡
├── 视频效果          ← 变换/扭曲/模糊与锐化/生成/颜色校正/键控/风格化…
└── 视频过渡          ← 见转场篇
```

用法：搜索框搜名字 → 拖到片段上；已加的效果在**效果控件面板**里调参数。

---

## 二、关键帧基础

1. 选中片段 → 打开**效果控件面板**；
2. 动「运动」组：**位置 / 缩放 / 旋转 / 锚点 / 不透明度**；
3. 点参数前的**秒表图标** = 打第一个关键帧；
4. 移动播放头、改参数 = 自动打第二个关键帧；
5. 移动播放头时按住 `Shift`，指针自动吸附到附近关键帧（精调对齐）。

---

## 三、蒙版与跟踪

1. 效果控件 →「不透明度」→ 三个蒙版图标：**椭圆 / 矩形 / 钢笔（自由画）**；
2. 画好后可调：**蒙版路径 / 蒙版羽化 / 蒙版不透明度 / 蒙版扩展**；
3. **手动跟踪**：蒙版路径右边「向前跟踪 / 向后跟踪」按钮，PR 逐帧跟着画面里的物体走；
4. 物体运动不规则时，隔几帧手动加一个蒙版关键帧修正。

> 蒙版两个用途：① 局部调色/局部效果（只让某区域变亮）；② 勾勒区域做转场/遮罩。

---

## 四、AI 对象遮罩（v26.0）

1. 选中有人/主体的片段；
2. 效果控件 →「不透明度」→「**对象遮罩**」按钮；
3. 框选要追踪的人/物 → PR 自动识别并逐帧生成蒙版；
4. 之后套色/模糊/抠像都基于这个蒙版。

费用：**免费（含在订阅内，Assistive AI），中国大陆可用**。

## 五、混合模式

效果控件 →「不透明度 → 混合模式」：

| 模式 | 用途 |
|---|---|
| 滤色（Screen） | 叠光效/光晕，黑色自动消失 |
| 正片叠底（Multiply） | 白色自动消失，叠白底图 |
| 叠加 / 叠加类 | 增强对比 |
| 溶解 | 颗粒感过渡 |

> 实操：光晕/光效素材层用「滤色」，白底 Logo 用「正片叠底」。

## 六、轨道遮罩键（Track Matte Key）

两层素材配合：

1. V2 放被遮罩的画面（要露出来的内容）；
2. V3 放"遮罩图"（黑白图/文字/动态图形）；
3. 给 V2 加「视频效果 → 键控 → **轨道遮罩键**」→ 效果控件里「遮罩」选 V3；
4. 结果 = V3 的白色区域透出 V2 画面。

用途：文字里填充视频、图形形状里塞画面。

## 七、抠像：超级键

### 1. 超级键（绿幕/蓝幕）

1. 效果面板搜「超级键」→ 拖到绿幕片段；
2. 效果控件里用**吸管点画面里的绿色**；
3. 微调：**透明度 / 高光 / 阴影 / 容差**；
4. 溢色处理：「遮罩生成 → 溢色抑制」去衣服上的绿光。

### 2. 其他键控

| 键控 | 适用 |
|---|---|
| 亮度键 | 画面明暗对比强：黑/亮区域变透明，"屏蔽度"从小到大 1~100 调 |
| 颜色键 | 抠单色背景，**不影响主体颜色**（比超级键温和） |
| 颜色平衡（RGB） | 配合键控做分色/三层处理 |

> 超级键与颜色键类似，但超级键会影响主体色调；要保主体颜色就用颜色键。

## 八、常用插件

- **Optical Flares**：AE 系光效插件，PR 里做镜头光晕/光斑，付费插件（试用带水印）。
- **RSMB**：变速后补运动模糊，见 [变速与慢动作](./变速与慢动作.md)。
- **Film Impact 过渡集**（26.2 内置引入的现代过渡包）：做故障/缩放类炫技转场，见 [转场创意与混剪实战](./转场创意与混剪实战.md)。
